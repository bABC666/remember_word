# Phase 2.9 文件预览切片记录（2026-09-24）

基线：设计提交 `e03bd82`。分支：`codex/phase-2-9-preview`，独立 worktree。此切片仅处理本地分隔文本文件；测试输入都是 pytest 临时目录中的合成数据。**2.9-A 主词表及证据化补充内容、2.9-B 考研真题词频均未验收。**

## 实现边界

- `backend/app/services/public_lexicon_preview.py` 从原始字节计算 SHA-256 和大小，按显式编码、分隔符、列名映射解码；报告原始行、映射后原值、`strip().casefold()` 规范词形、重复首见行号，以及解码、表头、缺值、列数和 CSV 格式错误。仅接受一条物理行一个记录；带跨行引号的记录会作为错误报告，不能被静默导入。
- `python -m app.cli public-lexicon preview FILE --source-root DIR --map word=HEAD [--map meaning=CN] [--required meaning] [--encoding utf-8-sig] [--delimiter ,]` 将 JSON 报告打印到标准输出。`word` 始终必填。命令没有确认、写入或报告文件输出选项，也不初始化或核验应用数据库。
- 当前规范词形仅用于预览匹配；不推断 lemma、不合并义项，不添加许可或频率结论。文件名不是去重键；原始字节 SHA-256 才是待后续确认流程使用的文件指纹。预览报告尚不是可确认的锁定计划。
- 没有新增 schema、迁移、正式来源文件、公共词条、用户学习状态或复习事件。该切片不提供普通用户可调用的网络端点。

## 代码审查修订与独立复核（2026-09-24）

审查提出三项边界问题后先补针对性失败测试，再修改实现：

1. **资源上限**：单文件原始字节最多 **8 MiB**、数据物理行最多 **20,000**、最终缩进 JSON 报告的 UTF-8 字节最多 **16 MiB**。前两项在解析/生成报告前拦截；读取至文件上限加 1 字节判断超限，避免先吞下任意大文件。报告完成后按与 CLI 输出相同的序列化方式测量，超限只返回 `file_too_large`、`too_many_rows` 或 `report_too_large` 明确错误，不输出半份报告。这是人工预览的保守资源预算：20,000 行覆盖通常的单份考研词表评估规模，8 MiB 约给每行平均 400 字节，16 MiB 容纳 JSON 行级元数据扩张；真实来源选定后应按实测文件体量复核预算，不能把上限当成来源许可或完整性结论。
2. **来源根目录**：CLI 必填 `--source-root`；服务先解析根目录及候选的实际路径，绝对路径、`..` 和符号链接／Windows junction 解析到根目录外均以 `outside_source_root` 拒绝。读取已解析的目标文件。测试在 Windows 无文件符号链接权限时跳过该平台测试，另用可创建的 junction 实测逃逸拒绝。
3. **CSV 物理行**：仅 CRLF、CR、LF 分隔物理行，U+2028 等 Unicode 字符保留在字段原文内；错误编码的行号亦按这三类换行计算。仍按“一条物理行一个记录”限制，跨行引用视为错误。

针对性测试先运行得到 **6 failed、1 skipped**（缺常量、根目录参数和 CLI 参数），CR-only 解码错误行号另得 **1 failed**；修订后聚焦测试 **16 passed、1 skipped**，另有依赖弃用警告。Windows junction 逃逸测试 **passed**。ruff `app tests` 与 `tools` 均 **All checks passed**。

## 下一切片的外部裁定

1. **2.9-A 主词表**：负责人需选定真实考研主词表、发布者和版本，核验内容使用/存储/展示/再分发许可，并固定原始文件字节指纹、结构、编码、更新策略。当前候选资料的网页事实不构成内容授权，也未确定哪个是真正的考研主词表。
2. **补充释义和音标**：逐份核对上游版权链、字段级许可、原文保留与展示范围，确定可用文件版本及字段映射；不能因仓库代码许可证就推定词典内容可使用。
3. **确认写入切片**：先裁定来源及许可，再设计来源证据与运行记录 schema、锁定预览计划、管理员本人复核和事务幂等；本切片的 JSON 报告不能直接作为写入授权。
4. **2.9-B 真题词频**：须有可合法使用、可复核的纯考研英语一/二题目或统计来源，明确年份、题型、计数单位、词形归并与缺年处理。混合考试计数不能标为考研真题词频；无合格证据时不显示伪精确数字。

在可发布验收前，还须在具备虚拟环境、前端构建物和隔离的 verified baseline 的受控环境重跑完整 `scripts/check.ps1`；不能借用或修改生产 `data/vocab.db` 来补齐本 worktree 的门禁条件。
