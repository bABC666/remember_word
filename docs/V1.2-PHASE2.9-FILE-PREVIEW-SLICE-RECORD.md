# Phase 2.9 文件预览切片记录（2026-09-24）

基线：设计提交 `e03bd82`。分支：`codex/phase-2-9-preview`，独立 worktree。此切片仅处理本地分隔文本文件；测试输入都是 pytest 临时目录中的合成数据。**2.9-A 主词表及证据化补充内容、2.9-B 考研真题词频均未验收。**

## 实现边界

- `backend/app/services/public_lexicon_preview.py` 从原始字节计算 SHA-256 和大小，按显式编码、分隔符、列名映射解码；报告原始行、映射后原值、`strip().casefold()` 规范词形、重复首见行号，以及解码、表头、缺值、列数和 CSV 格式错误。仅接受一条物理行一个记录；带跨行引号的记录会作为错误报告，不能被静默导入。
- `python -m app.cli public-lexicon preview FILE --map word=HEAD [--map meaning=CN] [--required meaning] [--encoding utf-8-sig] [--delimiter ,]` 将 JSON 报告打印到标准输出。`word` 始终必填。命令没有确认、写入或报告文件输出选项，也不初始化或核验应用数据库。
- 当前规范词形仅用于预览匹配；不推断 lemma、不合并义项，不添加许可或频率结论。文件名不是去重键；原始字节 SHA-256 才是待后续确认流程使用的文件指纹。预览报告尚不是可确认的锁定计划。
- 没有新增 schema、迁移、正式来源文件、公共词条、用户学习状态或复习事件。该切片不提供普通用户可调用的网络端点。

## 下一切片的外部裁定

1. **2.9-A 主词表**：负责人需选定真实考研主词表、发布者和版本，核验内容使用/存储/展示/再分发许可，并固定原始文件字节指纹、结构、编码、更新策略。当前候选资料的网页事实不构成内容授权，也未确定哪个是真正的考研主词表。
2. **补充释义和音标**：逐份核对上游版权链、字段级许可、原文保留与展示范围，确定可用文件版本及字段映射；不能因仓库代码许可证就推定词典内容可使用。
3. **确认写入切片**：先裁定来源及许可，再设计来源证据与运行记录 schema、锁定预览计划、管理员本人复核和事务幂等；本切片的 JSON 报告不能直接作为写入授权。
4. **2.9-B 真题词频**：须有可合法使用、可复核的纯考研英语一/二题目或统计来源，明确年份、题型、计数单位、词形归并与缺年处理。混合考试计数不能标为考研真题词频；无合格证据时不显示伪精确数字。

在可发布验收前，还须在具备虚拟环境、前端构建物和隔离的 verified baseline 的受控环境重跑完整 `scripts/check.ps1`；不能借用或修改生产 `data/vocab.db` 来补齐本 worktree 的门禁条件。
