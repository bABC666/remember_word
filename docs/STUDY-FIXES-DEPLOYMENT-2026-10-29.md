# 今日学习修复与部署总结（2026-10-29）

三项今日学习修复已于 2026-10-29 发布到既有阿里云 ECS 实例。本次 GitHub 提交包含实际运行源码、回归测试、部署脚本和冻结发布包。

## 行为变化

1. **当天强化复习**：首次答“不会、模糊”的词排在本轮其他待学词后继续练习，答“会”后当天结束。每天首次作答决定长期熟练度、下次复习时间及成功/失败统计；当天后续练习保留事件，但不重复推进长期熟练度或累计连续失败次数，也不多占新词额度。
2. **释义优先**：核心释义、词典释义、用户提供但未核实的释义位于上方；语义锚点及备注缩小到答案底部。原有词典来源义项和许可入口保留。
3. **恢复进度**：学习页根据服务器保存的当天答题记录恢复已学数量，切换页面或刷新后继续；保存失败时不跳过当前词。缓存按账号、词库请求和日期隔离。

“当天”沿用现有 UTC 日期规则，新词配额和队列读取上限沿用原实现。每日新词目标调整和词库选择功能保留。本次同时补齐此前已上线但尚未同步 GitHub 的阅读目标词黄色标记，使仓库构建保留该功能。
