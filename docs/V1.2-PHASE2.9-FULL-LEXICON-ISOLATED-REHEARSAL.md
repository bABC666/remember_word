# Phase 2.9：完整词表隔离库导入预演（2026-10-02）

## 输入和口径

起点为 `codex/phase-2-9-pos-meaning` 的 `c8e2a3c`。脚本只读已保全的 `raw/netem_full_list.json`、冻结 `out/plan-r4-v4en.json`，以及其对应的 zh.wiktionary v4en、WikDict CSV 与固定 wikitext 包。原始 JSON 和冻结计划均按 SHA-256 钉住；300 词的来源位置和值在重建计划时逐项比对。正式来源清单与四份原有未跟踪文档未改。

NETEM 的 `序号` 决定收词顺序；从 `单词` 生成 `word,netem_rank,freq_claimed_mixed_exam_corpus` 临时 CSV，导入映射**只有 `word`**。原始 `释义` 不进入临时 CSV，也不进入词条、证据或短释义。词频字段是来源自述的混合考试计数，仅用于本次输入复核，未映射到词条频率列。

冻结 300 词只作**原始字段默认值选择**：有非空 zh.wiktionary 释义即选它；否则选非空 WikDict 释义。两个来源的原文、物理行号及固定修订（适用时）均作为导入证据保留，未选一侧标为 `not_selected`。没有相交要求；此选择不构成按词性的短释义裁定。临时 manifest 把许可写为 `UNVERIFIED` 且只声明隔离预演用途，不表示许可获准。

原冻结 300 词计划有 237 个 `blocked`：236 个未选定的释义冲突及 `fertiliser` 的缺项。本次在临时计划中按上述固定优先级逐词写明字段选择；缺项保留空值并列入未解决项，因此整批可导入而无需制造释义。

## 例外与回归

- 原始表的 `March`（序号 5421）与 `march`（1989）、`May`（5425）与 `may`（68）在词条身份规则下各归为一词，保留较早拼写和顺序；后两行记入结果的 `duplicates`。这解释 5530 行与 5528 词条的差额。
- 冻结 300 词中仅 `fertiliser` 两源均无可用汉语释义，结果的 `unresolved` 单列 `no_preserved_meaning`。该词作为收词成员导入，默认来源释义为空；将「肥料」伪称来源原文的提案遭拒，HTTP API 无已确认短义。
- 其余 **5228** 个词是全量收词成员，但不属于冻结 300 来源切片，来源释义保持为空；没有用 NETEM 的 `释义` 填补。`key` 属此范围，已导入词条但**没有**已确认短义。
- `prior` 的 HTTP API 回读为形容词「先前的、更重要的」和副词「事先」；`performance` 为标注人工试判的名词「表演、执行、性能」。仅这 6 个既有试裁定代表短义在隔离库中由脚本确认。固定行与词性依据仍按 `40_isolated_e2e.py` 的路径校验。
