## 版本边界

建议将 **1.2.0 定义为本机多用户版**：应用继续只监听 `127.0.0.1`，提供账号、会话、权限隔离和本地学习流程。此边界与当前代码形态一致。Phase 2.9 的外部电子词库及系统公共词库交付、Phase 3 的移动端/PWA、Phase 4 的云端部署与公网访问均是后续工作，不列为 1.2.0 已交付能力。云端关闭 OCR 后的主要词条来源依赖 Phase 2.9；本候选不承诺云端可用。

本次仅统一项目版本：`backend/pyproject.toml`、`frontend/package.json`、`frontend/package-lock.json` 的顶层与根包条目、`backend/app/main.py` 的 FastAPI 版本均为 `1.2.0`。lock 文件中的依赖包版本保持原值。版本号表示**候选代码目标版本**，不是已发布状态。
