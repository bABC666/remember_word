# NETEM 前 1000 唯一词按词性短义实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 复用冻结 300 裁定和全量隔离导入，把 NETEM 首次出现的前 1000 唯一词逐词裁定并在新隔离库确认可证实的义项。

**Architecture:** 全量导入脚本负责会员顺序、原始来源和证据行。新裁定清单只记录词性、短义、原文针和取舍理由；解析器核对清单、原文与位置，隔离运行器调用既有提案/确认服务。缺证据项保留候选。

**Tech Stack:** Python、SQLite、SQLAlchemy、pytest；既有 Phase 2.9 脚本与固定来源包。

**Spec:** 用户本轮请求及 `docs/V1.2-PHASE2.9-FROZEN300-POS-ADJUDICATION.md`。

## Global Constraints

- 只用本地保全来源；NETEM 仅用于收词和顺序。
- 仅作用于前 1000 唯一词；重叠词沿用已提交 300 词裁定。
- 每词性组 1–3 条，非 300 切片 WikDict 的词性只能是裁定者试判。
- 所有操作指向新 `test-artifacts` 隔离库；不改生产库、正式来源清单或许可状态。
- 跑针对性测试与完整性检查后提交；不跑完整门禁、不合流。

## Review Focus

- 首次出现的唯一词顺序与前 1000 边界。
- 冻结 300 重叠词文字、词性、顺序不漂移。
- WikDict 全量包行指纹与原始 Stardict 位置可回查。
- 无来源、跨语言或缺证据项不显示；`key` 的“关键”不确认。
- API 词性分组及裁定者试判署名正确。
