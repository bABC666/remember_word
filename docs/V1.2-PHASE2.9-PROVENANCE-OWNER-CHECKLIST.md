# Phase 2.9 provenance 核对表（供负责人逐项裁定）

> **性质**：只读切片交付物。本文件**不是**可提交的 manifest，**不是**授权声明，**不是**验收记录。
> 它把"计划用于公共词库的每份真实来源"的 provenance 逐字段摊开：**哪一项有证据、证据在哪、还差什么人的决定**。
>
> **本切片没有做**：没有改导入器或释义规则；没有生成确认计划；没有运行 `confirm`、迁移或任何生产库写操作；
> 没有做逐词裁定；没有做 2.9-A/2.9-B 验收；没有发送任何授权询问；没有提交或推送。**因此没有跑 `check.ps1`（无代码改动）。**
>
> **基线**：`main` = `origin/main` = `dab71ec`（实测，工作区干净）。
> **证据来源**（仅读了这四类）：来源调研报告、真实数据预演切片记录、0008/0009 联合评审记录、
> 现有真实来源清单中与 provenance 直接相关的部分（仓库外 p29x 预演包的 manifest 与 provenance 草案）。

## 0. 怎么读这张表

三种标记，全文一致：

| 标记 | 含义 |
|---|---|
| `[已核实·本次实测]` | 本切片**本次**在磁盘/仓库上重新算过或读过原文，与文档声称一致 |
| `[已核实·文档留档]` | 文档里留有指纹/引句，本切片复核了它的**内部一致性**，但没有重抓来源站点 |
| `[待确认]` | **没有证据**或**只有负责人的政策判断能定** → 一律留空，**不得**写进正式 manifest 的必填字段 |

一条铁律（来自 0008 的设计与预检实现）：

> **字段非空 ≠ 授权成立。** 程序只能校验"声明得像不像"（形状、时间戳能解析、摘要 64 位小写十六进制、
> 非空白），**不校验声明为真**。`use_scope`/`display_scope` **没有文件可证**，它们是负责人的授权决定，
> 不是可以"查出来"的事实。因此本表把它们单列，**不许**用程序补全。

可程序校验的部分（核准依据：`backend/app/services/public_lexicon_joint_preview.py:30-153`、
`backend/app/models.py:563-609`、`backend/app/services/public_lexicon_target_preflight.py:37-42`）：

| 约束 | 内容 |
|---|---|
| 必填 6 项 | `publisher` ≤200 / `version` ≤120 / `obtained_at_utc` ≤40 / `license_id` ≤80 / `use_scope` ≤200 / `display_scope` ≤200（**空白即阻断** `incomplete_provenance:<source_id>`） |
| 可选 2 项 | `license_text_sha256` ≤64（**必须 64 位小写十六进制**）/ `storage_locator` ≤400 |
| 形状 | `obtained_at_utc` 必须是**带时区**的 ISO-8601 瞬时；未知字段名直接拒绝（防 `"license"` 这类拼写错误静默落空） |
| 数据库 | `source_artifact` 有 CHECK：6 个必填列 `trim()<>''`，否则插入失败（`ck_source_artifact_provenance_present`） |
| 显式"未批准"识别 | 值里出现 `未获批准`/`未获批`/`未经授权`/`not approved`/`pending approval` 等 18 个固定子串之一 → 预检报 `explicitly_unapproved`（**fail-closed**） |

## 1. 两个使用场景（每个来源都要分别问一遍）

| | **场景 I：两人家庭使用** | **场景 II：三人以上或公开使用** |
|---|---|---|
| 访问者 | 本人 + 1 位家人，两个具名账号 | 第 3 个账号、或任何形式的公开访问 |
| 商业性 | 不收费、不挂广告、不对外经营 | 公开部署后是否算商业优势需重新判定 |
| 分发 | 不对外分发数据库、不加 DRM、不限制其行使 CC 权利 | 向公众 Share → 触发 BY + SA 讨论 |
| NC 数据（NETEM） | 报告 §8.5 认定 NC 条件**满足**（这是报告结论，**不是**负责人的批准） | **必须先移出**（报告 §9 默认规则） |
| SA（相同方式共享） | 报告不向公众 Share → 不触发（§8.5） | **待核问题**：汇编还是改编、如何发布（§6.1(2) 三种解读，报告不下结论） |
| 本表现状 | `use_scope`/`display_scope` **仍是"预演草案·未获批准"** | **两个字段都还没有任何草案** |

**⚠ 场景 II 的现状必须说清**：p29x 包的草案只写了"未获批准"字样，**没有任何**针对场景 II 的 `use_scope`/`display_scope`。
换句话说：**当前清单在"三人以上或公开使用"下不成立**，不是"待补充文字"，而是**尚未评估**。
