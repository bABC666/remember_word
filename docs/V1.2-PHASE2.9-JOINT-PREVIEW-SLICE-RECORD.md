基线：本地 `main` 的 `5c7200d`。分支：`codex/phase-2-9-joint-preview`，独立 worktree。本切片继续来源无关的文件预览，只使用测试临时目录中的合成 CSV；GitHub PR #1 的 OCR 与 Phase 3 文件不在改动范围。**2.9-A 主词表与补充内容、2.9-B 考研真题词频均未验收。**

## 入口与报告

管理员本机运行 `python -m app.cli public-lexicon preview-many MANIFEST --source-root DIR`。`MANIFEST` 是 `DIR` 内的 JSON 文件，示例：

```json
{
  "required_fields": ["meaning"],
  "sources": [
    {"id": "primary", "file": "primary.csv", "columns": {"word": "head", "meaning": "cn"}},
    {"id": "supplement", "file": "supplement.csv", "columns": {"word": "term", "meaning": "translation", "phonetic": "ipa"}}
  ]
}
```

每个来源可另指定 `required_fields`（文件行级校验，默认仅 `word`）、`encoding`（默认 `utf-8-sig`）和 `delimiter`（默认逗号）。清单顶层 `required_fields` 是联合词条级缺字段判定，默认 `meaning`。清单最多 256 KiB，来源数 1–8，联合 JSON 报告最多 32 MiB；单来源继续遵守原有 8 MiB 文件、20,000 数据物理行、16 MiB 报告限制，超限返回明确错误。这些是人工审阅的资源预算，真实文件确定后须按体量复核。

每份文件先调用既有 `preview_file`，保留文件原始字节 SHA-256、映射、原始物理行和行级错误。联合报告按 `strip().casefold()` 后的词形聚合，稳定按来源 ID、词形、行号排序，并计算规范 JSON 的 `report_sha256`；交换来源在清单中的顺序，报告和哈希不变。每个 `word`、`meaning`、`phonetic`、`part_of_speech` 的证据独立列出来源 ID、文件指纹、行号、原始整行、原始词形和字段原值。可解析且有规范词形的行即使有缺值或文件内重复错误，仍进入联合证据；原错误同时留在来源报告。不可解析或空词形的行只在来源报告中说明，不能被猜测归入某词。

词条级缺字段按**所有来源中是否存在非空原值**判断；同词出现不同非空原始释义时给出冲突值列表。即使两份释义文本相同，证据也保留两份。预览不自动拼接、覆盖、挑选义项或推断词形还原；冲突列表只是审阅提示，不是采纳决定。`source_id` 是本地清单标识，不证明来源版本、许可、主词表资格或内容可展示性。此报告不是可执行确认计划，哈希也不是管理员授权凭据。

`--source-root` 仍是管理员控制、预览期间不被其他进程修改的本地目录。清单和来源文件均须解析到该目录内；CLI 不提供给普通用户。它未实现抵御不可信本机并发修改者的句柄级防护。命令不打开应用数据库、不创建公共词条、用户学习状态或复习事件；没有确认写入入口、schema 迁移、正式来源文件或生产库操作。字段集合不含词频，不把混合考试计数标为考研真题词频。

## 测试与门禁

先写合成测试：最初 5 项因联合服务及 CLI 尚不存在而失败；实现后 6 项通过。复核发现仅有一个来源且该行缺必填释义时，联合报告会漏掉可识别词形；针对性测试先得到 **2 failed / 5 passed**，随后修正为保留该行的空原值与行错误，聚焦测试 **7 passed**。覆盖来源顺序互换后的完整报告相等、两种释义冲突、相同释义证据双份保留、逐字段原值与文件指纹、缺字段、缺映射列、重复来源 ID、CLI 只读及清单越界拒绝。原始源文件与清单字节、测试库的 `LexiconEntry` / `UserWordState` / `ReviewEvent` 行数在 CLI 调用前后相同。

## 确认写入前仍需裁定

1. 指定经内容授权核验的考研主词表及版本、原始文件指纹和成员规则；补充来源不得自行扩展公共主词表。逐来源核验释义、音标的存储、加工、展示、再分发许可与原文保存范围。候选网页事实或代码仓库许可证不等于词典内容授权。
2. 裁定冲突义项和默认展示值、同词不同义项及词形还原、缺字段与错误行的排除或修复规则；更换来源版本时不得静默覆盖旧证据。当前报告未区分主来源与补充来源的候选成员，不能直接作为写入计划。
3. 另行设计并评审可锁定的预览计划、管理员本人确认、文件与映射指纹复核、事务写入、重复导入幂等、来源证据 schema/migration 与回滚；本分支不启动这些操作。
4. 2.9-B 需要合法且可核验的**纯考研**英语一/二真题语料与统计方法、年份、计数单位及覆盖范围。混合考试计数只可按原口径标识；缺可靠证据时不展示伪精确词频。
