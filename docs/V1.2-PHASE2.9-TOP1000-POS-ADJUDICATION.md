## 逐词记录和复跑

- `tools/phase29/top1000-decisions.tsv` 对每个新增词至少给出一项状态：`confirm`、`candidate` 或 `no_source`。确认行含词性、拟展示文字、命中的原文片段及取舍理由；同词性最多三条。多词性和不同重要义分行保留，重复、过窄、错误或混杂片段不作为展示义。`tools/phase29/top1000-pos-audit.tsv` 单列 38 个 WikDict 原包 `grammar` 标签与本轮词性试判不一致的片段，记录取舍：其中 6 条转为候选。
- `tools/phase29/top1000.py` 从固定原始 JSON 和 ZIP 重建 NETEM 顺序及全量 WikDict CSV 行号，检查清单覆盖、闭集词性、组内 1–3 条、中文文字、英文词头、原文针、StarDict 条目索引、字节位置及正文指纹。新增词只有 WikDict 原文，词性一律记作 **`reviewer`／“裁定者试判”**，不冒称 zh.wiktionary 词性小节标题。

- 复跑时从仓库根执行以下命令，并换一个**未存在**的隔离目录名：

  ```powershell
  backend/.venv/Scripts/python.exe tools/phase29/run_top1000.py --output test-artifacts/phase29-top1000-NEW
  backend/.venv/Scripts/python.exe tools/phase29/audit_top1000.py --output test-artifacts/phase29-top1000-NEW
  ```

  第一条命令复用全量隔离导入，跳过其原有的样例短义写入，在新库建立来源证据、固定 wikitext 行及提案；只对证据链通过的前 1000 词义调用确认服务。第二条经真实按词性 API 抽查并写入 `api-audit.json`。输出必须在 `test-artifacts` 下且不存在；脚本拒绝复用目录或指向 `data/`。许可状态仍为 `UNVERIFIED`，隔离确认仅表示文字和已保全证据可核对。
